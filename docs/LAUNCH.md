# خطة الإطلاق · Launch plan

الكود جاهز يتشغّل. دي الخطوات اللي فاضلة قبل ما يوصل لمدارس حقيقية، مرتّبة حسب الأولوية.

## 1. قبل التجربة مع مدرسة (أسبوع)
- [ ] تشغيل المشروع على Supabase وLiveKit وGemini بالخطوات اللي في README.
- [x] رفع الموقع على Vercel بدومين `fasli.site`.
- [ ] في Supabase → Authentication: تفعيل تأكيد الإيميل، وتعريب رسايل الإيميل (Email Templates)، وإضافة رابط الموقع وكود التطبيق `fasli://` في Redirect URLs.
- [ ] تجربة كاملة: مدرسة ← مدرس ← فصل ← رفع كتاب ← امتحان بالذكاء الاصطناعي ← طالب يحل ← تصحيح ← اعتماد ← ولي أمر يشوف.
- [ ] تجربة حصة مباشرة بين موبايل وكمبيوتر.

## 2. تجربة مجانية مع مدرسة واحدة (شهر)
- [ ] اختار مدرسة أو سنتر واحد، ويُفضّل يكون IGCSE.
- [ ] جمع ملاحظات المدرسين على جودة الأسئلة والتصحيح.
- [ ] مراقبة استهلاك الخطط المجانية (Supabase: قاعدة البيانات والتخزين، LiveKit: الدقائق، Gemini: عدد الطلبات).

## 3. قبل الإطلاق الرسمي
- [ ] **قانوني:** سياسة خصوصية وشروط استخدام. المنصة فيها بيانات أطفال، فمحتاج موافقة أولياء الأمور.
- [ ] **المتاجر:** حساب Apple Developer (99$ في السنة) وGoogle Play (25$ مرة واحدة)، وصور للمتجر ووصف بالعربي والإنجليزي.
- [ ] **النسخ الاحتياطي:** خطة Supabase Pro علشان النسخ الاحتياطي اليومي، لما يبقى فيه بيانات حقيقية.
- [ ] **الإشعارات:** Push notifications للحصص والامتحانات والدرجات (expo-notifications).
- [ ] **التحصيل:** نظام اشتراكات للمدارس (Paymob أو Stripe).

## 4. تطويرات بعد الإطلاق
- قراءة إجابات الطلاب المكتوبة بخط اليد من صورة.
- بنك أسئلة مشترك لكل مادة، وPast Papers للـ IGCSE.
- خريطة الفجوات للطالب المنقول من منهج لمنهج.
- تفريغ الحصة نصيًا وملخص تلقائي (LiveKit Egress + الذكاء الاصطناعي).
- تقارير PDF لأولياء الأمور.
- لوحة إدارة لأكتر من فرع للمدرسة.

## التكلفة المتوقعة في البداية
| الخدمة | مجاني لحد | بعدها |
|---|---|---|
| Supabase | 500MB قاعدة بيانات، 1GB ملفات، 50 ألف مستخدم نشط شهريًا | Pro بـ 25$ في الشهر |
| LiveKit Cloud | عدد دقائق مجانية شهريًا | حسب الاستخدام |
| Gemini | عدد طلبات يوميًا على Flash | حسب الاستخدام |
| Vercel (Hobby) | مجاني للاستخدام الشخصي | Pro بـ 20$ في الشهر للاستخدام التجاري |

> الأرقام بتتغير، فراجع صفحات الأسعار وقت الإطلاق.
